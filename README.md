# Awesome-Enterprise-Application-Platform

## Top Enterprise Application Platform Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Low-Code Development, Workflow Automation & Extensible Application Foundations*  

**Last updated: October 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Enterprise Application Platforms**. These tools provide the foundational runtime, visual builders, and integration layers that organizations use to build, extend, and operate custom business applications—from departmental workflow apps to mission-critical enterprise systems—without starting from a blank codebase.



**Examples** include ServiceNow Now Platform, Salesforce Platform, Microsoft Power Platform, Appian Platform, Pegasystems Infinity, Oracle Cloud Platform, SAP Business Technology Platform, Zoho One, Workday Enterprise Management Cloud, and Quickbase (the category leaders).



**Open-source emphasis**: This section is expanded with active projects for self-hosted low-code platforms, workflow engines, and application scaffolding frameworks—ideal for organizations building sovereign application infrastructure without per-user or per-app licensing lock-in.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[ServiceNow Now Platform](https://www.servicenow.com/)**  

  Enterprise application platform with App Engine Studio for visual low-code development, Flow Designer for automation, IntegrationHub for connecting external systems, and a unified data model across ITSM, HRSD, CSM, and custom apps; the platform emphasizes governed citizen development with delegated development controls and source control integration .



- **[Salesforce Platform](https://www.salesforce.com/)**  

  Metadata-driven application platform with Lightning App Builder for drag-and-drop page construction, Flow Orchestration for multi-step business processes, Prompt Builder for reusable AI prompt templates, and Shield for security and compliance; extends CRM data with custom objects, external data sources, and APIs .



- **[Microsoft Power Platform](https://powerplatform.microsoft.com/)**  

  Suite of low-code tools including Power Apps (canvas and model-driven apps), Power Automate (cloud and desktop flows with RPA), Power Pages (external-facing sites), Dataverse (unified data layer), and Copilot Studio (custom AI agents); 1,800+ connectors and AI-embedded Plan Designer that generates solution plans from natural language descriptions .



- **[Appian Platform](https://appian.com/)**  

  Low-code automation platform with Composer for AI-generated application plans from requirements documents, Agent Studio for building autonomous AI agents that can invoke each other as tools, and a data fabric for unifying enterprise data; positioned as a Leader in the 2026 Gartner Magic Quadrant for Business Orchestration and Automation Technologies .



- **[Pegasystems Infinity](https://www.pega.com/)**  

  Enterprise transformation platform with Pega Blueprint for AI-assisted workflow design, an always-on AI developer agent for real-time guidance, AI-powered RPA design via Robot Studio, and automated test generation; emphasizes predictive and compliant application delivery .



- **[Oracle Cloud Platform](https://www.oracle.com/)**  

  Includes Oracle APEX (Application Express), a fully managed low-code development and deployment platform on Oracle Cloud Infrastructure with Autonomous Database; enables browser-based application creation without additional tooling .



- **[SAP Business Technology Platform](https://www.sap.com/)**  

  Application development and automation platform with SAP Build offering low-code, pro-code, and generative AI tools; Joule Studio for creating custom AI agents and skills, ABAP AI capabilities for cloud migration, and integration with SAP Business Data Cloud .



- **[Zoho One](https://www.zoho.com/one/)**  

  Unified business platform with Creator for custom web and mobile apps using Deluge scripting, Flow for no-code integrations between Zoho and third-party apps, and Sigma for building widgets and extensions; apps deploy to employees, customers, or vendors within the Zoho ecosystem .



- **[Workday Enterprise Management Cloud](https://www.workday.com/)**  

  Unified platform with a built-in Business Process Framework (BPF) spanning HR, finance, and payroll; 850+ preconfigured business processes, event-driven workflow automation, and 100% audit trail capture for all process changes and executions .



- **[Quickbase](https://www.quickbase.com/)**  

  No-code platform with AI-powered Smart Builder for creating apps from spreadsheets or natural language, Smart Data for connecting ERP/CRM/legacy systems, Smart Insights for real-time dashboards, and Smart Governance for compliance; positioned for composable enterprise architecture without replacing existing systems .



## Open-Source GitHub Projects



- **[Budibase](https://github.com/Budibase/budibase)**  

  Open-source low-code platform focused on internal tools and workflow apps; visual builder for forms, tables, and automation; supports PostgreSQL, MySQL, MongoDB, and REST APIs; open-source version is feature-complete for self-hosting with active community development .



- **[Joget DX](https://github.com/jogetworkflow/jw-community)**  

  Open-source low-code application development platform combining BPM and visual development tools; supports cloud and on-premises deployment across multiple operating systems and databases; drag-and-drop designer with extensive documentation; suited for enterprise digital transformation use cases including supply chain and approval workflows .



- **[CUBA Platform](https://github.com/cuba-platform/cuba)**  

  Open-source enterprise rapid application development framework (Java); provides IDE and CLI tooling, Apache 2.0 licensing, and a rich plugin ecosystem including BPM; suited for complex business system rebuilds in manufacturing ERP and financial core systems .



- **[Saltcorn](https://github.com/saltcorn/saltcorn)**  

  Open-source no-code database management platform with visual dashboards and themed interfaces; built-in templates for blogs, project management, and other use cases; MIT licensed and available as an online demo; suited for small team internal tools like wikis and customer management systems .



- **[Metabase](https://github.com/metabase/metabase)**  

  Open-source data visualization and BI tool with support for MongoDB, Oracle, PostgreSQL, and more; interactive charts and maps; not a full application platform but essential for building analytics dashboards into enterprise applications .



### Additional Strong Open-Source Options



- **Appsmith** — Open-source low-code platform for internal tools with drag-and-drop UI, JavaScript customization, and 25+ database integrations; Apache-2.0 licensed and self-hostable.

- **ToolJet** — Open-source low-code platform with 80+ components, built-in database, and 90+ data sources; AGPL-3.0 community edition with Docker deployment.

- **Rintagi** — Mobile-first low-code platform with developer-friendly APIs for cross-platform PWA/iOS/Android apps .



**Frameworks for building custom systems**: Combine **Budibase** for internal workflow apps with multi-database support, **Joget DX** for BPM-heavy enterprise applications, **CUBA Platform** for Java-based complex business systems, and **Metabase** for embedded analytics dashboards in a self-hosted enterprise application platform stack.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Enterprise application platforms handling business data and workflows must comply with applicable privacy regulations and organizational governance policies; audit logging and access controls are critical for production deployments.

- Self-hosted open-source solutions vary significantly in scope—Budibase and Joget provide broad low-code development, while CUBA Platform targets complex Java enterprise systems; full enterprise application platform capabilities with multi-tenant governance, AI-assisted development, and deep integration ecosystems typically require commercial platforms.

- Verify license terms for commercial use; Budibase uses GPL-3.0 with paid enterprise features, Joget DX community edition is open-source, CUBA Platform uses Apache 2.0, and Saltcorn uses MIT .
